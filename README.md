# 🏡 Guestally

A full-stack **stay, hotel, and villa booking platform** where users can **discover properties, post their own properties, book accommodations, manage bookings, and get instant assistance through an integrated chatbot**.

Guestally connects **guests and property owners** through a simple platform for searching, listing, and booking stays.

---

## ✨ Features

* 🔐 **User Authentication**

  * Register
  * Login / Logout
  * User account management

* 🔎 **Property Search**

  * Search for stays, hotels, and villas
  * Browse available properties
  * View property details, images, pricing, and amenities

* 🏡 **Post Properties**

  * Property owners can list their stays
  * Add property title, description, location, price, images, and amenities
  * Manage posted properties

* 📅 **Property Booking**

  * Select check-in and check-out dates
  * Book available properties
  * Manage booking information
  * View booking history

* 🖼️ **Property Images**

  * Upload and display multiple property images
  * Showcase properties through an image gallery

* 🤖 **AI Chatbot**

  * Chat with the platform to ask queries
  * Get assistance while searching for properties
  * Ask questions about stays, bookings, and platform features

* 📱 **Responsive Design**

  * Optimized for desktop, tablet, and mobile devices

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
cd guestally
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file and configure the required environment variables:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
AWS_ACCESS_KEY_ID=your_aws_access_key
AWS_SECRET_ACCESS_KEY=your_aws_secret_key
AWS_REGION=your_aws_region
AWS_BUCKET_NAME=your_bucket_name
```

### 4. Start the Application

```bash
npm run dev
```

The application will start on the configured local development port.

## 🎯 Project Objective

The goal of **Guestally** is to provide a convenient platform where users can **discover and book hotels, villas, and other stays**, while property owners can **list and manage their accommodations**.

The integrated chatbot further improves the user experience by providing an interactive way for users to get answers to their queries throughout the booking journey.
